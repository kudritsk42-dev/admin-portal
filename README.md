# Корпоративная Wiki (SPA на React + Vite)

Внутренний wiki-портал без бэкенда: все данные живут в браузере (память + `localStorage`). Интерфейс целиком на русском языке, стили через MUI.

## Архитектура
- **SPA на React + TypeScript + Vite** с маршрутизацией `react-router-dom` (`/`, `/section/:id`, `/article/:id`, `/article/:id/edit`, `/upload`).
- **Состояние статей и разделов**: React Context (`src/state/ArticlesContext.tsx`) хранит мок-данные, синхронизирует изменения в `localStorage`, умеет добавлять/обновлять/удалять статьи и хранит глобальный поисковый запрос.
- **Компоненты**: общий `Layout` с AppBar/Search и Drawer-разделами, карточки статей, формы редактирования и загрузки.
- **Рендер контента**: `react-markdown` для отображения Markdown статей.
- **Классификация файлов**: `src/utils/classify.ts` подсказывает раздел по имени файла и переиспользуется на странице загрузки.

## Структура проекта
```
src/
├── components/          # Общие UI-компоненты (Layout, ArticleCard)
├── data/                # Мок-данные статей и разделов
├── pages/               # Страницы (Home, Section, Article, Edit, Upload)
├── routes/              # Маршрутизация приложения
├── state/               # Контекст для статей/разделов
├── utils/               # Утилиты (классификация файла)
├── App.tsx              # Корневой компонент маршрутов
└── main.tsx             # Точка входа, тема MUI, провайдеры
```

## Ключевые элементы
- **Layout** (`src/components/Layout.tsx`): AppBar с логотипом/поиском, левый Drawer с разделами и ссылкой на загрузку документов.
- **Домашняя страница** (`src/pages/HomePage.tsx`): последние статьи, плитки разделов, кнопки «Новая статья» и «Загрузка документа», поиск по заголовкам и тегам.
- **Страница раздела** (`src/pages/SectionPage.tsx`): фильтр по названию/тегам, список статей раздела.
- **Страница статьи** (`src/pages/ArticlePage.tsx`): Markdown-контент, теги (Chips), метаданные раздел/дата, кнопки «Редактировать»/«Удалить».
- **Создание/редактирование** (`src/pages/EditArticlePage.tsx`): поля заголовка, раздела, тегов, описания, markdown-контента; сохраняет/обновляет данные в контексте (маршрут `/article/:id/edit`, для новой статьи используйте `/article/new/edit`).
- **Загрузка документа** (`src/pages/UploadPage.tsx`): выбор файла, автоопределение раздела по имени, задание тегов, создание статьи с шаблонным текстом.
- **Классификация файла** (`src/utils/classify.ts`):
  - `exchange` → Почта
  - `rds` или `server` → Инфраструктура
  - `wifi` или `network` → Сети
  - `security` → Безопасность
  - иначе → Бизнес-системы

## Запуск на Ubuntu 24.04.3
1. Установите Node.js (рекомендуется через nvm):
   ```bash
   sudo apt-get update
   sudo apt-get install curl -y
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
   source ~/.bashrc
   nvm install 20
   ```
   Или через apt: `sudo apt-get install -y nodejs npm`.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запуск в dev-режиме:
   ```bash
   npm run dev
   ```
   Если открываете приложение вне localhost (например, из браузера на другой машине), используйте привязку к `0.0.0.0`:
   ```bash
   npm run dev -- --host
   ```
4. Сборка и предпросмотр прод-версии:
   ```bash
   npm run build
   npm run preview
   ```
   Чтобы открыть предпросмотр снаружи хоста, добавьте `--host` аналогично dev-режиму: `npm run preview -- --host`.
   Либо раздайте `dist/` любым HTTP-сервером (`npx serve dist`).

Готово: открывайте `http://localhost:5173` и работайте с корпоративной wiki без бэкенда.
